# ВП ТС ЕГЭ — веб-платформа тестирующей системы ЕГЭ

Учебный проект МАИ (Институт № 8, кафедра ОЦ-8). Реализация четырёх технических заданий:

| ТЗ | Подсистема | Где в репозитории |
|----|-----------|-------------------|
| ТС ЕГЭ.КЧ.ТЗ.001 | Клиентская часть: модули М1, М2, М4–М6 | [`web/`](web) |
| ТС ЕГЭ.СЧ.ТЗ.001 | Серверная часть: компоненты С1–С7, API `/api/v1`, WebSocket `/ws/v1` | [`server/`](server), [`api/openapi.v1.yaml`](api/openapi.v1.yaml) |
| ТС ЕГЭ.РКИМ.ТЗ.001 | Пакет КИМ: варианты, план, дерево ветвления, справочные материалы, инструкция, JSON Schema | [`kim/`](kim) |
| ТС ЕГЭ.АО.ТЗ.001 | Аналитика: перевод баллов, статистика, аномалии, отчётность | [`server/src/routes/analytics.ts`](server/src/routes/analytics.ts), [`web/src/modules/analytics`](web/src/modules/analytics) |

## Охват

КИМ содержит **только задания с кратким ответом** (часть 1, 12 заданий), которые проверяются автоматически
на сервере — как установлено в ТЗ серверной части (разделы 3.1 и 3.4 п. 1). Поэтому развёрнутых ответов
и модуля экспертной проверки М3 нет; импорт варианта с заданиями другого типа отклоняется.

## Запуск в Docker (PostgreSQL 16 + приложение + Nginx с TLS)

```bash
cp .env.example .env          # параметры (логин администратора, порты, имя сервера)
./deploy/init-secrets.sh      # Windows: powershell -ExecutionPolicy Bypass -File deploy\init-secrets.ps1
                              # пароли БД, мастер-ключ КИМ, пароль администратора, сертификат стенда
docker compose up -d --build  # https://localhost
```

Пароль первичного администратора — в `deploy/secrets/admin_password` (каталог не попадает в git и в образ).
Дальше персонал, сессии, распределение и КИМ заводятся в модуле «Администрирование».

Заполнить пустой стенд синтетическими данными (ТЗ СЧ NFR-30; пароли задаёт оператор, в БД — только хэши):

```bash
docker compose run --rm -e SEED_STAFF_PASSWORD='не короче 12 символов' -e SEED_PARTICIPANT_PIN=123456 \
  app node server/dist/cli.js seed-staging
```

Рабочее место участника готовит технический специалист: открывает на компьютере ссылку места
(организатор → аудитория → «Ссылки мест»). После этого участник входит с главной страницы: «Участник экзамена».

## Разработка

```bash
npm install
docker compose up -d db                     # или локальный PostgreSQL 16
export DATABASE_URL=postgres://ege:<пароль>@localhost:5432/ege ADMIN_LOGIN=admin ADMIN_PASSWORD='не короче 12 символов'
npm run dev                                 # API :8080, Vite :5173
```

Без `DATABASE_URL` сервер не запускается; автотесты работают в памяти (`STORAGE=memory`),
интеграционный тест хранилища — при заданном `TEST_DATABASE_URL`.

## Архитектура

```
web/      React 18 + TypeScript + Vite. Модули М1–М6 и аналитика — отдельные фрагменты сборки.

          PostgreSQL: migrations/, src/store.ts; служебные команды src/cli.ts.
deploy/   Nginx, инициализация ролей PostgreSQL, генерация секретов.

kim/      Пакет КИМ по ТЗ РКИМ (JSON Schema 2020-12) + валидатор `npm run kim:validate`.
api/      Спецификация OpenAPI 3.1.
docs/     Журнал архитектурных решений (ADR), конфигурация Nginx, трассируемость.
```

## Дизайн

Визуальный язык «Mint Glass» — светлое матовое стекло: около 90 % поверхности — оттенки белого на светло-сером
холсте (`#edf0ec`). Рецепт стекла снят с эталона: полупрозрачные белые карточки (50 % белого) с чёткой
однопиксельной кромкой сверху; элементы управления — заливка почти как у фона, белый ободок по контуру
и мягкое внутреннее свечение без внешней тени; выбранное — сплошной белый. Размытие (`blur(20px)`) — только
у плавающих слоёв (панель экзамена, меню, всплывающие уведомления, слой диалога).

Мята `#98fb98` — дозированно: слабое свечение холста сверху слева, знак, одна акцентная плитка на экран,
прогресс и «готово». Данные в графиках и таблицах — сланцевые, статусы всегда со значком и текстом,
обычное состояние («норма», «успех») — тихий текст без цветной плашки.

Шрифты — Onest (заголовки и крупные числа) и Golos Text (текст), поставляются со сборкой. Геометрия: высоты
элементов 40 / 44 / 48 / 56 / 64 px, радиусы 28 (панели) · 24 (карточки) · 16 (плитки) · 14 (элементы) · 999 (капсулы),
сетка bento из 12 колонок. Движение едва заметное: 140–280 мс, появление 480 мс с каскадом 40 мс только
на первом экране после загрузки; при `prefers-reduced-motion` анимации отключаются.

На экранах М1 (задание, сводка, итог) анимаций и переходов нет — требование ТЗ КЧ (раздел 6.6).
Для участников с ОВЗ — контрастная тема (текст ≥ 7:1, сплошные белые поверхности и рамки 2 px) и масштаб
150/200 %; при `prefers-reduced-transparency`, без поддержки `backdrop-filter` и в режиме принудительных цветов
стекло заменяется непрозрачными поверхностями. Подробнее — [ADR-004](docs/adr/ADR-004-design.md).
