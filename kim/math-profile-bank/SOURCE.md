# Учебный банк профильной математики

Источник: [отдел разработки КИМ, 360b1ba](https://github.com/MortemAdVos/razrabotkaKIMEGE/tree/360b1bab95c59fcbb133dab8b71ee3fe000cc7df/package). В банке 500 вариантов по 12 заданий. Материалы банка используются на учебном стенде и читаются сервером.

Восстановление из клона источника: `node scripts/sync-kim-bank.mjs /path/to/razrabotkaKIMEGE`. Скрипт читает зафиксированную редакцию из Git, проверяет SHA-256 исходных JSON, исправляет суммарное распределение сложности по позициям, добавляет нормативы времени со слайда 7 и использует инструкцию действующего экзаменационного интерфейса. Шкала перевода загружается отдельно.

Для передачи сырых учебных материалов используйте административный интерфейс. В сборку клиентского приложения банк не включается.
