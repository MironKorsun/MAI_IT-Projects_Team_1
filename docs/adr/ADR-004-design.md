# ADR-004. Визуальный язык «Mint Glass»: светлое матовое стекло

**Статус:** принято (заменяет вариант с Manrope / Inter и `blur(34px)`) · **Связанные требования:** ТЗ КЧ 6.6, NFR-17, NFR-24–NFR-28, Ц-2, Ц-6

- Около 90 % поверхности — оттенки белого на светло-сером холсте `#edf0ec`; ярких цветов и декоративных объектов нет.
  Система — серьёзный государственный экзамен, а не витрина сервиса: спокойная, ясная, без рекламных приёмов.
- Рецепт стекла измерен по эталону: карточки — 50 % белого, однопиксельная белая кромка сверху и по бокам
  (`inset 0 1px 0 #fff`), почти без внешней тени. Элементы управления — заливка близка к фону (10 % белого),
  белый ободок 1 px по контуру и мягкое внутреннее свечение (`inset 0 0 14px`), без тени; выбранное и активное —
  сплошной белый. Размытие `blur(20px) saturate(140%)` — только у плавающих слоёв: панель экзамена, меню,
  уведомления, выдвижное меню; у слоя диалога — `blur(6px)`.
- Мятный `#98fb98` — дозированно: слабое радиальное свечение холста сверху слева, знак «Σ», одна акцентная плитка
  на экран (не на экране задания), градиент настоящего прогресса, отметка «готово/сохранено». Мятные тона
  никогда не используются для текста; текст и значки — `#2b7444` и темнее (≥ 4,5:1).
- Данные — сланцевые (`#677191`), на графике распределения мятным выделены значения не ниже порога.
  Статусы — цвет + значок + текст; обычное состояние («норма», «успех», «Активен») — тихий текст, бейджи — только у исключений.
- Типографика: заголовки и крупные числа — Onest (600–650, плотный трекинг), текст — Golos Text (450).
  Крупные неподвижные числа — пропорциональные цифры, таймер, счётчики и таблицы — табличные.
  Шрифты (OFL-1.1) поставляются со сборкой — внешних обращений нет (NFR-17).
- Геометрия: высоты 40 / 44 / 48 / 56 / 64 px (плотные строки персонала / стандарт / крупные / XL / поле ответа),
  радиусы 28 · 24 · 22 · 16 · 14 · 12 · 999 px, сетка bento 12 колонок, на 1024–1279 px — узкая панель-«рельс»,
  меньше 1024 px — верхняя панель и выдвижное меню.
- Движение едва заметное: наведения 140 мс, переходы 200–280 мс, появление первого экрана 480 мс с каскадом 40 мс
  (класс `.anim` после первого кадра); при `prefers-reduced-motion` анимации отключаются.
- Экраны М1 (задание, сводка, итог, сбой) — без анимаций, переходов и плавной прокрутки, без модальных окон,
  прерывающих ввод (ТЗ КЧ 4.2, 6.6); фон неподвижен.
- Запасные режимы: контрастная тема (текст ≥ 7:1, сплошные белые поверхности, рамки 2 px), масштаб 150/200 %
  (одна колонка, липкая панель с таймером, компактная полоса заданий); `prefers-reduced-transparency`,
  отсутствие `backdrop-filter` и `forced-colors` — непрозрачные поверхности и системные цвета.
