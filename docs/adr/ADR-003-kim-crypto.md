# ADR-003. Шифрование КИМ и выдача ключа по старту

**Статус:** принято · **Связанные требования:** ТЗ КЧ FR-04, NFR-19; ТЗ СЧ FR-29–FR-31, NFR-21; ДП-04, ДП-13

- При импорте (`POST /kim/imports`) содержимое варианта без эталонов шифруется AES-256-GCM случайным ключом варианта;
  ключ варианта обёрнут мастер-ключом криптомодуля (`KIM_MASTER_KEY` или файл вне БД с правами 0600).
- Эталоны и критерии хранятся отдельно и никогда не передаются клиентам.
- Пакет аудитории (`GET /rooms/{id}/kim-package`) выдаётся заранее только по секрету рабочего места, поддерживает Range.
- Ключ (`GET /attempts/{id}/kim-key`) выдаётся только после старта аудитории; на соседних местах — разные варианты.
- Клиент расшифровывает вариант Web Crypto API и сверяет SHA-256 с контрольной суммой из пакета.
- Локальная очередь ответов М1 шифруется неизвлекаемым ключом AES-GCM 256 бит в IndexedDB и удаляется после
  конечного состояния попытки.
