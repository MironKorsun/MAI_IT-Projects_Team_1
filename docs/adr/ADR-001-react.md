# ADR-001. Библиотека построения интерфейса — React

**Статус:** принято · **Связанные требования:** ТЗ КЧ NFR-06, NFR-18, приложение Б

Матрица решений приложения Б ТЗ КЧ: React 4,75, Angular 4,65, Vue 4,50. Принят React 18 + TypeScript,
запасной вариант — Angular.

Последствия:
- бюджет NFR-06 (JS ≤ 250 КБ сжатого для М1) выполняется: М1 ≈ 160 КБ gzip (React 54 КБ, KaTeX 79 КБ, модуль 15 КБ);
- модули подключаются через `React.lazy`, поэтому код М1 не загружается в М6 и наоборот (ТЗ КЧ 3.2);
- HTML из КИМ не вставляется через `innerHTML`: санитайзер по белому списку строит элементы React (NFR-18);
  `dangerouslySetInnerHTML` используется только для вывода KaTeX с `trust: false`.
